## 1. О приложении

LY Objects — приложение для учёта технических объектов, оборудования, фотографий, PDF, других документов и рабочих заметок на Android. Для локальной работы регистрация в LY Objects не требуется. Основная база данных хранится на устройстве. Разработчик не получает автоматически содержимое локального архива при обычной офлайн-работе.

## 2. Состав и источники данных

Пользователь самостоятельно добавляет названия, адреса и описания объектов, характеристики и расположение оборудования, координаты, технические заметки, фотографии, схемы и документы. Они могут включать персональные данные других людей, если пользователь самостоятельно их добавит. Пользователь должен иметь законные основания для внесения такой информации.

Для функции поиска близлежащих объектов приложение может получать координаты устройства с разрешения Android. Выбор файлов и фотографий происходит посредством системных средств Android. Индексация текста PDF осуществляется локально на устройстве и не требует отправки содержания документа разработчику.

## 3. Сторонние сервисы

**Яндекс ID и Яндекс Диск.** Подключение необязательно. При входе через Яндекс ID приложение получает сведения, необходимые для работы с подключённой учётной записью, и защищённый токен доступа. При создании ручной или включении автоматической резервной копии данные пользователя передаются в его Яндекс Диск. Обработка этих данных на стороне Яндекса регулируется правилами сервиса. Без подключения этой функции данные приложения не отправляются в Яндекс Диск.

**Голосовой ввод.** Для преобразования речи в текст приложение использует системные средства Android. В зависимости от настроек устройства обработка голоса может выполняться сторонним сервисом. LY Objects не сохраняет исходную аудиозапись.

## 4. Резервное копирование Android

LY Objects отключает стандартное автоматическое резервное копирование данных приложения средствами Android. Для сохранения информации пользователь может самостоятельно создать ZIP-архив или подключить Яндекс Диск.

Перенос данных между устройствами может также зависеть от производителя телефона и его собственных служб. Созданные вручную резервные копии не удаляются автоматически при удалении приложения.

## 5. Хранение, удаление и срок обработки

Локальные записи и вложения хранятся до удаления пользователем или очистки данных приложения. Перемещённые в корзину элементы остаются доступными до окончательного удаления из корзины. Удаление приложения удаляет локальный архив в пределах стандартного поведения Android, но не удаляет ранее созданные резервные копии на Яндекс Диске или в других облачных сервисах (в том числе копии из предыдущих версий приложения). Пользователь управляет такими копиями в соответствующей учётной записи.

Отключение Яндекс ID останавливает дальнейшее использование подключения, но не уничтожает автоматически уже загруженные копии. При необходимости удаления данных на стороннем сервисе необходимо воспользоваться его средствами или обратиться к соответствующему оператору.

## 6. Безопасность и разрешения

Приложение использует локальное хранилище Android и средства изоляции данных приложений; сетевые соединения для Яндекс Диска защищаются HTTPS. Приложение может использовать разрешения на местоположение и микрофон в связи с доступными функциями, а также доступ к сети. Наличие таких мер не гарантирует абсолютную защищённость устройства, сети и сторонних сервисов.

## 8. Изменения политики

При существенном изменении возможностей приложения и обработки данных политика обновляется. Актуальная редакция с датой вступления в силу публикуется по общедоступному HTTPS-адресу, указанному в карточке RuStore и настройках приложения.
